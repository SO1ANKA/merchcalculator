# «Твой Мерч»

Статическое приложение для запасов мерча, расчётов, маркетов и полок. Ретро — основное оформление; переключатель «Я серьёзный человек» в настройках включает классический вид с теми же данными.

## Запуск и публикация

Для просмотра нужен HTTP(S), например `python3 -m http.server 8765` из этой папки. Через `file://` ES-модули не запускаются.

Архив `tvoy-merch-github-pages.zip` содержит готовые файлы **для корня** репозитория GitHub Pages, включая `index.html`, модули, стили и `assets`. Загружать нужно весь комплект. Сборка и установка зависимостей не нужны. В этой задаче публикация не выполнялась.

## Данные

Учёт и фото хранятся локально. Совместная работа, друзья, сервер и синхронизация пока не подключены. Сохраняйте JSON-копии через настройки.

Основная версия сохраняет прежние имена хранилищ: `solyanka-state-v1`, IndexedDB `solyanka-local`. Обновление не требует миграции. Отдельная локальная демоверсия в `tvoy-merch-retro` использует изолированные хранилища. `?demo=1` запускает временный пример без сохранения его изменений в личные данные.

## Оптимизация загрузки · 23 октября 2026

- `render-shell.mjs` сохраняет статичные DOM-элементы шапки, боковых панелей и звёзд; рабочая область обновляется из актуального состояния.
- `photo-cache.mjs` хранит до 64 недавних фото, дополнительно удерживая видимые. Ненужные blob URL освобождаются; смена демо очищает кэш.
- Фото скрытых страниц списка читаются при показе страницы. При переключении разделов недавние фото повторно используются.
- Service worker отдаёт установленную версию сразу из кэша. Новая версия требует изменения номера `CACHE` в `sw.js`; установка нового кэша атомарная. Старые PNG-адреса поддерживаются для уже открытых вкладок.
- 25 PNG заменены WebP без потерь: 25 507 143 → 16 360 854 байт (−35,9%). Разрешение и RGBA-пиксели проверены на точное совпадение. Авторские исходники остаются в папке материалов; локальная копия до оптимизации — `work/before-performance.zip`.
- Убраны повторные вычисления прогнозов внутри одного обновления, поиск выбранных товаров выполняется через Map. Проверка наличия для плана строит остатки один раз. Формулы расчётов и формат сохранений прежние.

## Проверки

`node --test tests/*.test.mjs` — 76 проверок расчётов, данных, Telegram, кэша, пагинации, фото и совместимости.

`tests/render-shell.html` при открытии через HTTP выполняет 12 браузерных проверок сохранения элементов и актуальности форм. На локальной демке дополнительно проверены каталог из 14 товаров с фото, листание, повторный заход в раздел, выбор количества, классическое оформление и тёмная тема. Проверка проводилась в браузере, не на физическом телефоне в Telegram.
