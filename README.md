# «Твой Мерч» · визуальный эксперимент 1

Отдельная рабочая версия на базе 1.6, созданная для сравнения нового оформления с основным приложением. Полный разбор референсов и решений — в [DESIGN.md](DESIGN.md).

## Запуск и публикация

Это статическое приложение без сборки и собственного сервера. Для просмотра нужен HTTP(S), поскольку код использует ES-модули. Через `file://` приложение может не запуститься.

Для GitHub Pages загрузи папку `retro` из архива **целиком в отдельную подпапку** репозитория. Не заменяй файлы основной версии в корне.

- Приветствие и собственные тестовые запасы: `https://so1anka.github.io/merchcalculator/retro/`
- Готовый пример без сохранения: `https://so1anka.github.io/merchcalculator/retro/?demo=1`

Адреса заработают после загрузки и успешного развёртывания GitHub Pages. Автоматической публикации в этой сессии не было.

## Что сохранено

Инвентарь, два режима калькулятора, акции, прогноз, маркеты, полки, продажи, резервные копии и демо работают как в версии 1.6. `domain.mjs` совпадает с основной версией байт в байт. Сеть, друзья, помощники и платежи не подключены.

## Что изменено

Основная тема находится в `retro.css`: голубые рамки и заголовки, сдержанный глянец, красные основные действия, тёмная сине-серая тема. В приветствии — портрет чибика и именная плашка у пояснения. Референсы не встраиваются в приложение.

IndexedDB, localStorage, Telegram DeviceStorage и кэш service worker имеют отдельные идентификаторы. Личные данные основной версии не читаются и не изменяются; перенос возможен вручную через JSON-копию.

## Проверка

Команда: `node --test tests/*.test.mjs`.

57 тестов прошли, включая защиту данных основной версии от записи и удаления кэша экспериментом. Визуальная проверка в браузере и Telegram на телефоне ещё нужна.


## Оформления

Ретро включено по умолчанию. Переключатель «Я серьёзный человек» в настройках возвращает спокойный классический вид. Данные и незавершённый расчёт общие, перезагрузка и импорт не нужны. Повторное выключение переключателя возвращает ретро.
