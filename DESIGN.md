# «Твой Мерч» — облик 03

Отдельный визуальный эксперимент на базе версии 1.6. Основное приложение в `outputs/solyanka` не изменено. Предыдущий облик 02 сохранён в отдельном архиве.

## Откуда взяты приёмы

Изучены реальные HTML и CSS трёх сайтов:

- [DokoDemo](https://dokode.moe/indexv3.html), [CSS](https://dokode.moe/stylesheets/v3.css): отдельные цветные панели, небольшие виджеты, иллюстрированные заголовки, сочетание спокойного фона и ярких деталей.
- [Cinni’s Dream Home](https://cinni.net/), [CSS](https://cinni.net/style.css): рисованные рамки, орнамент, небольшие самостоятельные окна. Две маленькие картинки крыльев временно включены в эксперимент; ссылки в `ASSET-CREDITS.md`.
- [Melankorin](https://melankorin.net/): тонкие контуры, плотные панели, штриховые фактуры, персонаж как часть композиции.

Чужие страницы и скрипты целиком не копировались. Собственная разметка и CSS сохраняют функции миниаппы и подстраиваются под телефон. Сторонние картинки лежат локально: приложение не загружает их с сайтов авторов.

## Что изменилось

На широком экране — боковое меню, рабочее окно, календарь с отметками запланированных маркетов, ближайший маркет и кнопка резервной копии. В шапке — логотип на бумажной карточке и персонаж перед окном подсказки. Календарь показывает текущий месяц; ближайший маркет открывается кнопкой.

На телефоне боковые панели скрыты, остаётся нижняя навигация. Рабочие формы занимают ширину окна. Большая шапка не показывается во время расчёта. График окупа получил сегментированную полосу; формулы остались прежними.

Светлая тема включается при каждом запуске. Внутри сеанса доступна графитовая тёмная тема. Надпись «Добавить» получает ширину по содержимому; строка поиска имеет единственную рамку.

## Изоляция

Отдельные IndexedDB `tvoy-merch-retro-local`, ключ localStorage / Telegram DeviceStorage `tvoy-merch-retro-state-v1`, кэш `tvoy-merch-retro:` с областью по папке. Данные основной миниаппы автоматически не читаются. JSON-копии совместимы для ручного переноса. Ссылки с `?demo=1` открывают демо без сохранения изменений.

## Проверка

61 автоматическая проверка прошла: расчёты, остатки, продажи, резервные копии, выход из демо, изоляция хранения и кэша. Проверка шаблонов теперь использует реальные подписи целей из приложения, а не подставные значения: это ловит пропавшее объявление при изменении разметки.

В браузере проверены запасы, форма добавления, простой расчёт и его итог, про-режим, обе темы и возврат к светлой после перезагрузки. На ширине 320 px нет горизонтального переполнения, подпись кнопки добавления помещается. Нативный Telegram на iOS и Android в этой проверке не использовался.

## Запуск в Telegram

При запуске в Telegram 8.0+ приложение один раз вызывает `requestFullscreen()`. Старые клиенты остаются развёрнутыми через `expand()`. Системные отступы и отступы интерфейса Telegram учитываются сверху, снизу и по бокам; они обновляются при изменении полноэкранного режима. Если пользователь выйдет из него вручную, приложение не пытается принудительно вернуть его обратно. В обычном браузере полноэкранный режим не запрашивается.

Проверено на имитации Telegram API: современный/старый клиент, ошибка запроса, уже включённый режим, изменение отступов, обычный браузер. Проверка на реальном устройстве в Telegram ещё требуется. Документация: https://core.telegram.org/bots/webapps#initializing-mini-apps
